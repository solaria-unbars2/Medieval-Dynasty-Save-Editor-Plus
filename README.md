### Requisitos do Sistema

Para garantir o melhor desempenho e estabilidade, verifique se seu sistema atende aos seguintes requisitos:

- **Sistema Operacional**: Windows 10 (versão 1809 ou posterior) ou Windows 11 (64-bit). Sistemas de 32-bit não são suportados.
- **Processador**: Intel Core i3, i5, i7 ou equivalente AMD, com pelo menos 2.0 GHz de clock. Processadores mais recentes oferecem melhor desempenho.
- **Memória RAM**: 4 GB ou mais. Para edições complexas de saves, 8 GB são recomendados.
- **Armazenamento**: 500 MB de espaço livre em disco para instalação da ferramenta, além de espaço para backups dos saves.
- **Jogo**: Medieval Dynasty instalado e atualizado para a versão mais recente. A ferramenta não inclui o jogo; você precisa comprá-lo separadamente.
- **Conexão com a Internet**: Necessária para download, atualizações e registro opcional.
